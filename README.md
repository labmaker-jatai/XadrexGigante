# ♟️ Xadrez Gigante

Projeto de um **tabuleiro de xadrez gigante fabricado em MDF utilizando corte a laser**.

O modelo foi desenvolvido para ser utilizado em **eventos, atividades educacionais, oficinas e aulas de xadrez para turmas grandes**, permitindo que as peças e os movimentos sejam visualizados com facilidade por todos os participantes.

Os arquivos disponibilizados neste repositório podem ser utilizados para **fabricação, edição e adaptação do projeto** em diferentes equipamentos de corte e fabricação digital.

## 📁 Arquivos disponíveis

| Formato | Descrição |
|---|---|
| `.dxf` | Arquivo vetorial compatível com softwares CAD e diversos equipamentos de fabricação digital, incluindo máquinas de corte a laser. |
| `.wcvr` | Arquivo para utilização em cortadoras **Delta CNC**. |
| `.jpeg` | Fotografia do modelo após a fabricação. |

## 🛠️ Fabricação

O projeto foi desenvolvido para fabricação em **MDF por corte a laser**. Os arquivos vetoriais podem ser adaptados conforme as dimensões desejadas e as especificações da máquina utilizada.

A imagem `.jpeg` disponível neste repositório apresenta o resultado do modelo após a fabricação.
